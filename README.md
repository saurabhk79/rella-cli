# Rella CLI

Rella CLI is a command-line interface for interacting with the Rella platform.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/rella-cli.git
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```

## Usage

To use the Rella CLI, run the following command:

```bash
npx rella <command> [options]
```

## Commands

- `ai`: Interact with the Rella AI.
- `config`: Manage the Rella CLI configuration.
- `plugin`: Manage Rella CLI plugins.
- `run`: Run a Rella task.
- `session`: Manage Rella sessions.
- `update`: Update the Rella CLI.
